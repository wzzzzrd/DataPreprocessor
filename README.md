# DataPreprocessor

Тестовое задание по стажёрской программе IT HUB «Северстали»

## Описание проекта
Класс `DataPreprocessor` предназначен для базовой автоматизированной очистки и трансформации данных в формате `pandas.DataFrame`.

### Основные возможности:
- **Удаление пропусков**: Автоматическое удаление столбцов по заданному порогу и заполнение оставшихся пропусков (mean/median/mode).
- **One-Hot Encoding**: Преобразование категориальных строковых данных в числовой формат.
- **Нормализация**: Приведение числовых данных к единому масштабу (нормализация Min-Max или стандартизация).
- **Логирование**: Сохранение всех параметров трансформации в атрибут `history` для обеспечения воспроизводимости.

## Как запустить
